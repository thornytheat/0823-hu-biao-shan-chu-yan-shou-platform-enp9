# 批次操作

1. 用带异常样例做阶段预览，查看列数、必填值和冲突记录。
2. 执行批次后，在业务阶段定位异常分组并核对原始记录键。
3. 修复来源文件，重新上传并执行。历史批次保留供复核。
4. 对账无差异且无坏行时可签发。对仍有差异的版本可填写暂缓意见。
5. 导出复核证据并保存于交接记录。
6. 月末审计需要复验旧快照时，在批次复核区选择“回看原快照”；值班补录则上传补录 CSV 并填写稳定的补录键。
7. 等值剔除生成新的当前库存版本；悬空位置剔除会把当前版本置为暂缓并标出原记录。网络或进程中断后，用同一补录键重试，或调用恢复接口；不会重复生成签发结果。

单文件 256 KiB，最多 2000 条逻辑记录。容器重启后保留批次。恢复时使用原 Docker Compose 数据卷。
